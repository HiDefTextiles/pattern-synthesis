Five ways to grow a Sjónabók refill

A refill is a long woven or embroidered band. Here we try to knit one that never ends: original motifs from Íslensk sjónabók sit on a centre line, and a computer invents the stitches in between. This page explains, in plain words, five different ways of doing the inventing, and shows what each one produces on the same banner.

How to read the charts

Each chart is a banner lying on its side. Top to bottom is the knitting width, 85 needles on the Passap. Left to right is the length, one column per knitted row; scroll sideways to follow it. Border bands from the book run along both edges, and twenty-one original motifs sit on the centre line, always the same ones in the same order, so the only thing that changes between charts is the method filling the gaps.

With Copied vs new on, everything taken straight from the book is drawn grey, every invented stitch blue, and invented stitches that happen to recreate an exact 8×8 block from the book are drawn ochre. Switch to Pattern only to see the banner as it would be knitted in two colours.

Every chart is reproducible: the same settings and the same seed always give exactly the same stitches.
